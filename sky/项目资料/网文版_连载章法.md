# 《星云过后的青禾》连载章法

## 每章都要有人要失去东西

### 常用章末钩子模板

1. **身份钩：** “监控里那个替陆总挡刀的人，叫萧云策。”
2. **关系钩：** “方琳的手机屏幕亮起，来电人备注是：哥哥。”
3. **证据钩：** “那份药房签收单上，签的不是萧兰的名字。”
4. **公开处刑钩：** “热搜第一：#许青禾到底有几个男人#。”
5. **事业反杀钩：** “许青禾关掉PPT，说：‘项目暂停。责任我来签。’”

### 高甜必须带刀

| 甜点 | 紧接着的刀 |
|---|---|
| 陆星朗替许青禾挡酒、送她回家 | 方琳在车外拍到照片，第二天以“未婚妻”身份发难 |
| 萧云策在雨夜把外套盖到她肩上 | 许青禾发现他离开那年其实就在同一座城，却从未找她 |
| 方井彦替她争到项目主导权 | 她发现这正是把她推向舆论靶心的第一步 |
| 陆星朗公开解除婚约 | 董事会要求许青禾离职，以证明两人不存在利益输送 |
| 萧云策交出录音 | 他因保全证据受伤，录音也带出陆家最丑陋的秘密 |

### 女主反杀底线

许青禾可以被冤枉、失恋、失业边缘、被围剿，但不能连续被救。每10—15章必须有一次由她主动做出的漂亮决定：

- 用工作记录反杀“小三”谣言；
- 主动下线功能，反转隐私舆情；
- 不接父亲式羞辱的封口费；
- 拒绝陆星朗“我养你”的保护性安排；
- 在董事会上主动公布项目损失、要求独立审计；
- 不用萧云策的牺牲作为复合理由。
