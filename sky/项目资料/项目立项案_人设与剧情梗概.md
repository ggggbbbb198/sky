# 《星云过后的青禾》项目立项案

## 人物设定与剧情梗概

> 从被选择，到自己掌舵
>
> 2026.08 · 内部创作资料

## 一、项目定位

> **一句话梗概：** 被前任长期缺席、事业亦受挫的许青禾，进入运动科技公司芯动力后因一次广告救场走红。她在继承人、旧爱与学长的权力博弈中，从被推上舞台的人，成长为能够决定星动集团方向的掌舵者。

**类型：** 都市职场情感 + 商战悬念 + 豪门家族秘密。

**核心看点：** 运动科技品牌升级、女性职场上位、隐秘血缘、旧爱重逢、公众舆情与企业继承权的交错。

**情绪基调：** 前段是爱里沉溺与失控；中段是旧伤重新渗入日常；后段是看清、失去与成长后的清醒。

**女主弧线：** 被选中、被保护、被质疑 → 自己判断、自己承担、自己掌舵。

## 二、世界观与企业结构

星动集团是国内头部运动服饰与器材集团，正处于品牌年轻化、科技化升级期。董事长陆知远将集团的未来押在智能运动生态上。

集团收购运动穿戴科技公司后，将其更名为“芯动力”。该公司既保留了原有的产品研发能力，也承担星动面向年轻消费者的品牌创新任务。方井彦在收购后出任芯动力总经理。

路可物流是星动的重要合作伙伴，也是方氏家族的产业根基。方琳家掌握路可的控制权；方井彦则相信，路可原本应有父亲的一半，因此对方琳一家的恨意从未真正消失。

| 组织 | 公开定位 | 剧情作用 |
|---|---|---|
| 星动集团 | 运动服饰、器材与运动生活方式集团 | 陆星朗的继承权核心；许青禾最终掌舵的舞台。 |
| 芯动力 | 星动收购后的运动穿戴科技子公司 | 许青禾的职业起点；方井彦掌握的经营阵地。 |
| 路可物流 | 星动的世交与重要合作伙伴 | 方井彦复仇与夺回家族利益的真正目标。 |

## 三、主要人物设定

### 许青禾｜女主角 / 未来经营者

**公开身份：** 名校市场营销专业毕业。因原公司发展不顺、又无法忍受男友萧云策长期失联式的相处，跳槽进入芯动力市场体系。她青春、干净、健美，与运动品牌的新势力形象高度契合。

**内在驱动：** 她既渴望被看见，也害怕自己只是被谁选中的“幸运儿”。她真正要证明的，是自己不仅能成为镜头里的形象，更能成为定义品牌与企业方向的人。

**与许青禾的关系：** 方井彦是她大学学长与职场引路人；陆星朗是给她舞台、也愿意尊重她边界的恋人；萧云策是无法轻易放下的旧爱；沈兰因是她最可靠的闺蜜。

**人物走向：** 从广告救场、被公众关注，到面对裙带质疑、企业危机与情感撕裂，最终以经营与战略能力成为星动真正的掌舵者。

### 陆星朗｜男主之一 / 星动继承人

**公开身份：** 星动集团市场部总监，董事长陆知远的公开长子和未来继承人。自幼跟随父亲出入商务场合，对公司运营与人心运转有近乎本能的熟悉。

**内在驱动：** 他并非最擅长复杂算计的人，却有识人、授权和承担责任的能力。过去半推半就维系与方琳的关系，许青禾出现后才第一次明确地选择自己真正想要的人。

**与许青禾的关系：** 他欣赏许青禾的专业与生命力，给她资源却不替她决策；对萧云策从警惕到信任，最终成为彼此保护许青禾与集团的盟友。

**人物走向：** 父亲病故后接班。他需要证明自己并非只靠姓氏，并学会与许青禾共同领导，而不是把她留在“被保护者”的位置。

### 方井彦｜核心反派 / 芯动力总经理

**公开身份：** 许青禾大学学长，曾任校学生会主席，许青禾是副主席。精明干练，收购后升任芯动力总经理。方琳的堂兄，萧云策同母异父的哥哥。

**内在驱动：** 父亲与方琳父亲共同创业，后者在父亲身亡后吞并股份；母亲萧兰又被权力与关系拖入失控人生。他把失去的家庭、公司和许青禾都视为必须夺回的东西。

**与许青禾的关系：** 起初是许青禾的照顾者与解题者；陆星朗的出现让他感到被夺走。面对弟弟萧云策，他把血缘当成可利用的工具。

**人物走向：** 从有能力、有伤口的引路人，滑向以路可控制权为核心目标的操盘者。后期为了胜利，感情、方琳与弟弟都可以被牺牲。

### 萧云策｜旧爱 / 安全与风险处置者

**公开身份：** 退役特战人员，进入顶级安保公司后成为陆星朗身边的贴身安全人员与风险处置骨干。能力出众，却缺乏学历、资本与公开身份带来的话语权。

**内在驱动：** 他是陆知远从未承认的儿子，也是陆星朗隐秘的同父异母手足；对父亲的遗弃和母亲的利用都怀有深重怨恨。过去他习惯独自承担，才失去了许青禾。

**与许青禾的关系：** 他始终维护许青禾，也因陆星朗给他的尊重而认同这个“弟弟”。与方井彦的对立，是两兄弟对同一份创伤给出的相反答案。

**人物走向：** 在方井彦的最终阴谋中，他选择保护陆星朗与许青禾，并为此重伤致残、永久退出高风险安保。许青禾与他完成告别，沈兰因随后委任他为安保总监，邀请他去东南亚开旅馆。

### 方琳｜情感与舆情对手 / 路可千金

**公开身份：** 路可物流集团二小姐，同时拥有艺人身份与公众影响力，是星动的重点代言人。她习惯拥有资源、关注和被优先选择的生活。

**内在驱动：** 广告事故后，她失去主角位置；与陆星朗分手后，又认定许青禾夺走了自己原本的人生。她真正失去的是“我应该站在权力中心”的确定感。

**与许青禾的关系：** 她起初处处刁难许青禾，后被方井彦拉入同盟。两人先互相利用，继而发生关系；她最终看清方井彦的残酷，却已被其反噬。

**人物走向：** 在丑闻、背叛与资源崩塌后陷入严重的心理危机并接受治疗。她不是单纯的恶女，而是选择了错误报复方式的悲剧人物。

### 沈兰因｜闺蜜 / 娱乐公关从业者

**公开身份：** 许青禾在大院里一起长大的伙伴，娱乐公关从业者，喜欢怼人和在陌生城市流浪的洒脱独立女性。她自由、直接，表面不太可靠，关键时刻从不掉链子。

**内在驱动：** 她极懂公众情绪和娱乐圈套路，前期嘴硬嫌弃萧云策，认定他的失联和克制伤害了许青禾；在一次次看见他的沉默守护后彻底“真香”，确认自己爱上了他。她的爱不以占有为前提，也不会为了私心伤害许青禾。

**与许青禾的关系：** 她帮助许青禾判断舆情真伪、识别方琳的公众攻势，也是最早读懂萧云策沉默守护的人。

**人物走向：** 与方琳形成镜像：同样有爱而不得的时刻，方琳选择报复与占有，沈兰因选择朋友和底线。她前期嘴硬嫌弃萧云策，后来在沉默守护中彻底真香；萧云策重伤致残、退出一线后，她委任他为安保总监，邀请他去东南亚开旅馆。

### 陆知远｜星动董事长 / 父权与秩序的象征

**公开身份：** 星动集团董事长，陆星朗之父。重视门第、秩序与企业控制，反对陆星朗与许青禾的感情，认定她的出身与艺人身份不利于继承布局。

**内在驱动：** 他拒绝承认与萧兰所生的萧云策，试图把一切不符合家族秩序的关系从人生中抹去。

**与许青禾的关系：** 他的病重与死亡引爆继承危机，也使萧云策、陆星朗与许青禾被迫直面多年隐秘。

**人物走向：** 他留下的不是答案，而是一个必须被下一代改写的权力体系。

### 萧兰｜秘密枢纽 / 失控的母亲

**公开身份：** 方井彦与萧云策的母亲，曾与陆知远有隐秘关系。她生下萧云策，却始终没能得到陆知远承认。

**内在驱动：** 长期被遗弃、否认和失去安全感，使她把两个儿子的命运与自己的不甘混在一起。她希望以方井彦的经营能力和萧云策的行动能力，为他们争取一个进入星动权力中心的位置。

**与许青禾的关系：** 在方井彦安排下以护工身份进入陆知远病房。她向病重的陆知远揭开两个儿子的身份与位置，触发陆知远对继承权被夺的极度恐惧。

**人物走向：** 她并非冷静的谋杀者，而是在最后一次“讨名分”的冲动里，成为方井彦利用的棋子。

## 四、关系与秘密结构

| 关系线 | 表面关系 | 隐秘真相 / 冲突 |
|---|---|---|
| 许青禾 × 陆星朗 | 上级与被发掘的新面孔，后发展为恋人。 | 门第、职场权力与公众质疑使他们必须证明感情不等于资源交换。 |
| 许青禾 × 萧云策 | 分手多年的旧恋人与保护者。 | 爱仍在，但过去的失联、沉默与阶层差异没有自动消失。 |
| 许青禾 × 方井彦 | 大学学长、职场引路人与直属领导。 | 方井彦把帮助与占有混为一谈，最终将她视为可被摧毁的对象。 |
| 陆星朗 × 萧云策 | 总监与贴身安保人员。 | 实际为同父异母手足；陆知远从未承认萧云策。 |
| 方井彦 × 萧云策 | 同母异父兄弟。 | 同样承受萧兰带来的创伤，却分别走向控制与守护。 |
| 方井彦 × 方琳 | 堂兄妹与家族竞争者。 | 方井彦利用她的爱情、舆论资源和脆弱处；方琳最终被反噬。 |
| 沈兰因 × 萧云策 | 青梅圈里的熟人。 | 沈兰因前期嫌弃他的失联，后来在沉默守护中真香；萧云策重伤后，她委任他为安保总监，邀请他去东南亚开旅馆。 |

## 五、剧情梗概

### 第一幕：跳槽与被看见

许青禾离开原公司，也结束了与萧云策的关系。她以为自己需要的是一个更高的平台，却在芯动力发现直属领导竟是大学学长方井彦。方井彦熟悉她的能力，给她照顾、机会与看似无微不至的保护。

星动年度重点是年轻化与科技化。芯动力负责首支智能运动产品广告，陆星朗亲临把关。代言人方琳因突发状况无法到场，原本参与方案的许青禾自告奋勇顶上。她不仅符合品牌形象，更凭对产品与市场的理解完成救场，广告引爆关注。

### 第二幕：上位与爱情的错位

广告成功后，许青禾被推入公众视野。陆星朗从欣赏她的判断与韧性开始，在结束与方琳的关系、并处理好汇报边界后追求她。许青禾在熟悉的方井彦与更开阔的陆星朗之间犹豫，最终选择了愿意给她舞台、却不替她决定人生的陆星朗。

方井彦表面维持冷静，内心却逐步失衡；方琳则把广告、感情与身份上的失去全部归咎于许青禾。萧云策以陆星朗身边安保人员的身份出现，他一次次在许青禾看不见的地方挡下风险，也让那段未能好好结束的感情重新“会呼吸”。

### 第三幕：血缘揭开，继承危机爆发

陆知远病重。方井彦借萧兰的执念，让她以护工身份进入病房，揭开自己与萧云策的身份：一个已掌管科技子公司，一个多年守在陆星朗身边。萧兰希望陆知远承认她与萧云策，并幻想两个儿子能够“一文一武”进入星动的权力中心。

病重的陆知远却把一切理解为夺权信号。在对私生子、继承人和集团失控的恐惧中，他急性病发去世。陆星朗被迫接班，萧云策也因身世曝光而成为董事会与舆论眼中的不稳定因素。方井彦终于拥有了撬动整个集团的裂缝。

### 第四幕：路可之战与最终选择

方井彦的真正目标是夺回路可物流。他与方琳暂时结盟：方琳提供公众影响力、娱乐圈渠道与对陆星朗私生活的了解；方井彦则利用芯动力与供应链关系，制造足以让陆星朗失去董事会信任、让许青禾失去公众信任的连环危机。

方琳在关系与合作中看清方井彦的残酷，试图抽身却遭反噬。萧云策识破方井彦的布局，在保护陆星朗、许青禾与关键证据时付出重大代价。沈兰因以娱乐公关的专业识别舆情操弄，为许青禾争取公开回应的窗口。

最终，许青禾不再依赖谁替她开路。她以对品牌、团队与供应链的判断击穿方井彦的布局，保住星动与芯动力的未来，也让路可的历史旧账回到应有的责任与规则之中。陆星朗接过董事长的位置，许青禾成为集团经营与战略的真正掌舵者。

## 六、结局情感落点

事业上，许青禾与陆星朗形成互相信任的领导搭档：他提供治理、资源与承担，她以能力决定业务和未来。她不再是“被陆星朗选择的女孩”，而是可以和他并肩做决定的人。

感情上，萧云策仍是许青禾最深的旧痛与未竟之爱。两个人都明白，爱并不能抹去当初的伤，也不应成为彼此再度受伤的理由。其最终命运与两人的关系形态，将决定故事是克制遗憾、开放余韵，还是彻底悲剧。

## 七、后续开发待锁定事项

1. 萧云策“牺牲”的具体形态：死亡、重伤退场，或失去职业与身份。该选择直接决定终局的悲剧浓度。
2. 许青禾、陆星朗与萧云策的最终情感状态：稳定伴侣、克制同行，或以事业共同体替代传统圆满。
3. 方井彦最终布局的具体证据链与董事会对抗方式：需以一个核心商业目标贯穿，避免危机过于分散。
4. 年龄与时间线：建议锁定陆星朗、萧云策的出生先后，以及萧兰进入陆知远人生的具体节点，使“公开长子”与“实际年长的未被承认之子”完全自洽。
5. 正式书名：**《星云过后的青禾》**。后续如开发续作，可沿用“星空后的青禾”系列名。
