## 🔧 具体修订建议

### 第1章：补充大学时期的操控细节

**现状**：
- 只提到方井彦给了数据帮助许青禾通过答辩
- 缺少他"替她做决定"的具体情节

**建议修改位置**：第53行附近

**补充内容示例**：
```markdown
第二年，学长利用学生会和学院实践项目的便利，给了她一套脱敏后的行业数据与案例。

"你原来的课题太激进，改成这个方向更稳。"方井彦说，"我已经帮你调整好了框架。"

许青禾看着那份新的提纲，想说自己其实还想坚持原来的方向。

"相信我。"他说，"你以后会感谢我的。"

她重新答辩通过了。
```

**效果**：
- 体现他"我比你更了解你需要什么"的思维
- 为后续操控行为埋下根源
- 许青禾对他的感激和依赖有了更深的基础

---

### 第3章：强化面试中的惜才与投资思维

**现状**：
- 方井彦在面试中只是沉默的面试官
- 缺少他"选人"背后的判断逻辑

**⚠️ 重要提示**：
- ❌ 不要暗示他大学时就喜欢许青禾（会降低操盘者格局）
- ❌ 不要写"不会再被抢走"（暗示曾经失去，与人设冲突）
- ✅ 应该体现：惜才、投资思维、"适合的人放在适合的位置"

**建议修改位置1**：第11-33行（面试场景）

**补充内容示例**：
在第33行"会议室静了片刻"之后，增加方井彦的内心独白：
```markdown
会议室静了片刻。

方井彦看着她，心里已经有了答案。

五年前在学生会，她就是这样——能看到别人看不到的点，也愿意把最难的事做到底。

这样的人，留在那家老国企太可惜了。

HR合上简历："我这边没有问题。"
```

**建议修改位置2**：第47-51行（欢迎邮件）

**修改前**：
```markdown
【恭喜。大学时你总能把最乱的事理清，我一直相信你会走到更大的地方。欢迎来芯动力。】
```

**修改后**：
```markdown
【恭喜。你的思路和我当年预判的一样。芯动力需要你这样的人。】
```

**效果**：
- "我当年预判"体现他的投资眼光，而非情感依恋
- "芯动力需要你"是工作需求，不是个人占有
- 为后续占有欲的**渐进式萌发**留出空间

### 第4章：补充房子推荐中的越界细节

**现状**：
- 第58行方井彦发消息推荐房子
- 但缺少"他如何知道她在找房"的细节

**建议修改位置**：第58行之前

**补充内容示例**：
```markdown
手机正好亮起。

方井彦发来消息：【听说你在找房？】

许青禾愣了一下。她只跟沈兰因提过，方井彦怎么知道的？

还没来得及回复，第二条消息就跳了出来。

【我有个朋友要出国，房子闲置中。有没有兴趣，帮忙还一下月供？】

后面跟着一处公寓定位，离公司只有两站地铁。

许青禾把聊天界面亮给沈兰因。

沈兰因看了一眼，低声道："他怎么知道你找房？该不会在关注你的朋友圈吧。"

"可能是同事提过。"许青禾说。

"也可能是他一直在留意你的动态。"沈兰因挑眉，"在一起，在一起！"
```

**效果**：
- 暗示方井彦在"关注"她的生活
- 埋下第8章"租房天意是他"的伏笔
- 沈兰因的调侃增加可读性，同时点出不对劲

### 第5章：优化青屿岛情节（已写得很好，微调即可）

**现状**：✅ 这一章方井彦的温柔照顾写得很好

**可选优化点**：第159-167行

**现在的对话**：
```markdown
"答案够了吗？"

许青禾看着墙上的旧照片，又看向他。

"不够。"

方井彦点头。

"那晚上再看一场。"
```

**可优化为**：
```markdown
"答案够了吗？"

许青禾看着墙上的旧照片，又看向他。

"不够。"

方井彦笑了："我就知道你会这么说。"

"你又能读心术了？"

"不是读心。"他说，"我只是比别人更了解你。"

他转身往篝火的方向走："晚上再看一场。这次我保证，你会满意。"
```

**效果**：
- 加入"我比你更了解你"的核心台词
- 既温柔又隐约越界
- 为后续操控升级做铺垫

### 第6章：补充他控制信息节奏的细节

**现状**：
- 方井彦用"出海看答案"吸引许青禾
- 但缺少他"故意吊胃口"的心理描写

**建议修改位置**：第19行附近

**补充内容示例**：
```markdown
方井彦：【想知道答案，明天跟我一起出海吧。】

许青禾盯着那两行字看了很久。

为什么不直接说？为什么一定要她跟着去？

但她最终还是回了。

【好。】

方井彦看着屏幕上那个"好"字，笑了。

他知道她会答应。

她一直都是这样，只要给她一个足够好的理由，她就会跟上来。

大学时是这样，现在也是。
```

**效果**：
- 揭示他的操控思维："我知道你会答应"
- 体现他在"引导"而非"邀请"
- 增加读者的不安感

---

### 第7章：补充方井彦对赵忠布局的暗示

**现状**：
- 第7章主要写赵忠的失败
- 方井彦的戏份较少，多为被动（被冤枉、被平反）

**建议修改位置**：第219-230行（最后的晚餐场景）

**现在的场景**：
```markdown
夜里，高级餐厅临江而建。

方井彦坐在落地窗前。

...

对面的身影藏在灯光照不到的地方。银灰色长裙垂过椅脚，裙面被水光切成一层层冷白的折痕。她没有抬脸，只伸出一只手，托起酒杯。

"恭喜你，哥哥。"

方井彦与她轻轻碰杯。

"这一杯，该我敬你。"
```

**建议补充**（在最后一句之后）：
```markdown
"这一杯，该我敬你。"

方琳放下酒杯："赵忠那么蠢，你怎么忍了他这么久？"

"因为他有用。"方井彦说，"他越是想压住市场部，星动就越容易看出谁是真正在做事的人。"

"所以你从一开始就知道，陆星朗会选你？"

方井彦没有回答，只是笑了笑。

他从不赌运气。

他只赌人心。
```

**效果**：
- 揭示方井彦的操盘思维：利用赵忠做对比
- "他只赌人心"呼应母亲萧兰"把人当筹码"
- 为后续更大的布局做铺垫

### 伏笔2：方井彦"把人当筹码"的来源

**建议在第5章补充**：
- 在青屿岛的场景中，加一段方井彦的回忆
- 暗示他童年被送走、失去家庭的创伤

**补充位置**：第159行附近

**补充内容示例**：
```markdown
"答案够了吗？"

许青禾看着墙上的旧照片，又看向他。

方井彦也看着那些照片。照片里，岛民们围着他笑，像家人。

他很久没有过家人了。

父亲去世后，叔叔把他送到远房亲戚家，每年给两万抚养费。那些亲戚收了钱，却从不让他上桌吃饭。

后来他考上大学，再也没有回去过。

许青禾是他在学生会遇到的。她认真、努力，做事从不推诿。

他第一次觉得，有人可以信任。

"不够。"许青禾说。

方井彦回过神来。

"那晚上再看一场。"
```

**效果**：
- 解释他为什么对"失去"这么敏感
- 为他的控制欲提供心理根源
- 增加人物的立体感和悲剧性
