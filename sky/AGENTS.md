# 本项目为《星云过后的青禾》网文创作项目。

## 写作任务默认规则

- 用户要求创作、续写或修改正文时，默认先读取 `创作规范/写作总控.md`。
- 按 `创作规范/写作总控.md` 指定的资料优先级读取相关文件；至少读取 `创作规范/文字质感.md`、`项目资料/网文版_强狗血大纲.md`（总览）和 `正文/` 中与当前章节相邻的正文，并按章节需要读取人物、分卷、伏笔和情感线模块。
- 若涉及伏笔回收、特定人物状态或时间线验证，应主动读取 `审查记录/` 目录下的相关进度表（如伏笔回收、人设行为记录等）。
- `项目资料/网文版_强狗血大纲_母本.md` 仅作历史存档，除非需要核对遗漏或冲突，否则不作为日常写作的默认读取文件。
- 不要求用户重复提醒行文基调；每次交付前执行写作总控中的“写作后自检”。
- 当前有效剧情版本是 `项目资料/网文版_强狗血大纲.md`；与较克制的旧方案冲突时，以网文版为准。
- 新章节应延续上一章的语言、信息边界、人物状态和章末钩子，不擅自提前揭示未到节点的身份秘密。
- 正文使用 Obsidian Markdown 文件，章节文件放在 `正文/` 目录。
